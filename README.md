# 🛒 API Backend E-Commerce

API REST développée avec **Node.js** et **Express.js** permettant de gérer le backend d'une plateforme e-commerce. Cette application intègre un système de paiement via les solutions **Wave**, **Orange Money** et **Free Money**.

---

## 🚀 Fonctionnalités

- 🔐 Authentification des utilisateurs
- 👤 Gestion des utilisateurs
- 🛍️ Gestion des produits
- 📦 Gestion des commandes
- 💳 Intégration des paiements Mobile Money
  - Wave
  - Orange Money
  - Free Money
- 🔒 Sécurisation des routes
- 📡 API REST

---

## 🛠️ Technologies utilisées

- Node.js
- Express.js
- JavaScript
- API REST
- dotenv

## ⚙️ Installation

### 1. Cloner le projet

```bash
git clone https://github.com/Momar-dev/E-Commerce-Backend-avec-int-gration-paiment-wave-orange-money---free-mone.git
```

### 2. Accéder au dossier

```bash
cd E-Commerce-Backend-avec-int-gration-paiment-wave-orange-money---free-mone
```

### 3. Installer les dépendances

```bash
npm install
```

### 4. Configurer les variables d'environnement

Créer un fichier `.env` et renseigner les variables nécessaires.

### 5. Lancer le serveur

```bash
npm start
```

ou

```bash
node server.js
```
